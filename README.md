# IA Ingresos 30

Repositorio del sistema completo del infoproducto **IA Ingresos 30** (Albert Sierra, 2026): el libro, el workbook, el manual de producción de vídeo y el embudo de ventas.

## Estructura

```
docs/         → Embudo de ventas (landing, venta, gracias). Listo para GitHub Pages.
contenido/    → Manuscrito, workbook y manual de producción (.docx)
assets/       → Portada y diagrama del Método 5D
```

## Publicar el embudo con GitHub Pages

1. Sube este repositorio a GitHub (ver instrucciones más abajo).
2. En el repo, ve a **Settings → Pages**.
3. En "Build and deployment" → **Source**, elige **Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta **/docs**, luego **Save**.
5. GitHub publicará el sitio en `https://<tu-usuario>.github.io/<nombre-repo>/` en uno o dos minutos.
   - La landing (`index.html`) quedará en la raíz de esa URL.
   - La página de venta en `/venta.html` y la de gracias en `/gracias.html`.
